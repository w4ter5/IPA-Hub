# IPA Hub

Отдельное iPhone-приложение для загрузки IPA из GitHub Releases или по прямой HTTPS-ссылке и подписи на самом устройстве. Основано на открытом Feather; исходная лицензия GPL-3.0 и авторские сведения сохранены.

## Как пользоваться

1. Установите собранный IPA Hub на iPhone через ваш действующий способ установки (например, eSign).
2. Откройте вкладку «Подпись IPA» и один раз импортируйте `.p12`, `.mobileprovision` и пароль к `.p12`. Эти файлы не отправляются в GitHub.
3. Shadow уже добавлен как первый источник. Можно добавить другие публичные GitHub-репозитории или прямые HTTPS-ссылки на `.ipa`.
4. Нажмите «Скачать и подписать», затем «Сохранить или отправить подписанный IPA».

Для GitHub используется **последний опубликованный Release с IPA**, а не исходники репозитория и не `shadow-update.json`. Сейчас это позволяет избежать ссылки на ещё не опубликованную сборку. Приватные репозитории и ссылки, требующие авторизации, в этой версии не поддерживаются.

## Сборка

Проект требует Xcode 26 и macOS. Откройте `Feather.xcodeproj` и соберите схему `Feather`, либо запустите GitHub Actions workflow `Release` вручную (`workflow_dispatch`). При успешной сборке результат появится как артефакт `IPA-Hub`. На компьютере, где готовился проект, установлен только Command Line Tools. Запуски GitHub Actions на Xcode 26.3 и 26.6 завершились внутренним сбоем Xcode во время загрузки Swift-пакетов, до компиляции приложения. Работоспособность IPA пока не подтверждена.

Сертификат для подписи **других IPA** импортируется на iPhone после установки IPA Hub. В код, GitHub-репозиторий и GitHub Actions его класть не нужно. Для установки самого IPA Hub нужен подходящий способ подписи.

## Ограничения

- Подпись и установка зависят от совместимости `.p12`, `.mobileprovision`, Bundle ID, разрешённых устройств и срока действия профиля.
- Готовый IPA передаётся через системное меню «Поделиться»; автоматическая установка другой программы не входит в этот экран.
- Feather сохраняет сертификат и пароль локально в хранилище приложения. Не публикуйте резервную копию данных приложения вместе с личными сертификатами.
- Исходный Feather распространяется по GPL-3.0; если распространяете изменённое приложение, сохраняйте лицензию и публикуйте соответствующий исходный код.
