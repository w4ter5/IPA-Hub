# IPA Hub

Отдельное iPhone-приложение для загрузки IPA из GitHub Releases или по прямой HTTPS-ссылке и подписи на самом устройстве. Основано на открытом [Feather](https://github.com/khcrysalis/Feather) (автор — Samara, [@khcrysalis](https://github.com/khcrysalis), и участники проекта); исходная лицензия GPL-3.0 (`LICENSE`) и описание оригинального проекта (`UPSTREAM-README.md`) сохранены. Подпись выполняет [zsign](https://github.com/zhlynn/zsign) (MIT, см. `Zsign/LICENSE`).

## Как пользоваться

1. Установите собранный IPA Hub на iPhone своим способом установки (например, через eSign).
2. На вкладке «Подпись IPA» нажмите «Добавить .p12 и .mobileprovision», выберите оба файла и введите пароль от `.p12`. Файлы и пароль остаются в хранилище приложения на iPhone и никуда не отправляются.
3. Shadow (`https://github.com/folzy1092/Shadow`) уже добавлен первым источником. Через «Добавить источник» можно добавить другие публичные GitHub-репозитории (`https://github.com/владелец/репозиторий` или `владелец/репозиторий`) или прямые HTTPS-ссылки на `.ipa`. Источники можно удалять и менять местами.
4. Нажмите «Скачать и подписать» у нужного источника. Приложение:
   - найдёт файл `.ipa` в последнем опубликованном GitHub Release (без черновиков и пре-релизов) или возьмёт прямую ссылку;
   - скачает его (с прогрессом и кнопкой «Отменить») и проверит, что это ZIP-архив с `Payload/*.app`;
   - подпишет на iPhone выбранным сертификатом (используются настройки подписи Feather из «Настроек»);
   - сохранит результат в «Файлы» → «На iPhone» → IPA Hub → Archives → IPA Hub.
5. Сразу после подписи IPA Hub предлагает установить приложение на этот iPhone (встроенный установщик Feather; iOS покажет запрос «Установить»). Позже это можно сделать кнопкой «Установить» у источника или из «Библиотеки». Автоустановку можно выключить переключателем «Устанавливать сразу после подписи».
6. «Поделиться» сохраняет подписанный IPA в «Файлы» или открывает его в другом приложении (например, в eSign).

Приватные репозитории и ссылки, требующие авторизации, не поддерживаются. Без авторизации GitHub API разрешает около 60 запросов в час с одного IP.

## Сборка

GitHub Actions → workflow **Release** → «Run workflow» (`workflow_dispatch`). Готовый файл — артефакт `IPA-Hub` (`IPA-Hub.ipa`, не подписан, ставится через eSign или другой подписчик). Собирается только версия для iPhone (около 10 минут). Локально: macOS + Xcode 26, `make`.

### Что было сломано и что исправлено

- **Падение Xcode 26.3/26.6 при загрузке Swift-пакетов** (`-[NSMutableArray insertObjects:atIndexes:]: count of array (32) differs from count of index set (31)`). В оригинальном Feather из проекта убрали LicensePlist, но обновили только `Feather.xcworkspace/.../Package.resolved`, а `make` собирает `Feather.xcodeproj`, который читает `Feather.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved`. В нём оставались 8 уже ненужных пакетов и SWCompression 4.8.6 вместо требуемой 4.8.7. Файлы синхронизированы.
- **Подписанные приложения без профиля.** В используемой версии zsign `embedded.mobileprovision` удалялся при запечатывании приложения, поэтому iOS отказалась бы его устанавливать. Исходники zsign перенесены в `Zsign/` с исправлением (`Zsign/IPA-HUB-CHANGES.md`).
- **Неверный пароль `.p12` считался успехом.** zsign в этом случае возвращает ошибку, не вызывая обработчик, и Feather выдавал неподписанное приложение как подписанное. Теперь показывается ошибка подписи.

## Что проверено и что нужно проверить вручную

Проверено без iPhone: разбор адресов источников; поиск IPA в последнем Release Shadow через GitHub API (нет релизов / нет репозитория / нет `.ipa` — понятные ошибки); скачивание Shadow.ipa (~75 МБ) с прогрессом и проверкой архива; подпись извлечённого `Telegram.app` через тот же zsign на macOS тестовым самоподписанным сертификатом и профилем (вшивается профиль, пересчитываются `CodeResources`, неверный пароль даёт ошибку); сборка IPA в GitHub Actions.

Нужно проверить на iPhone с вашими файлами:

1. Установка `IPA-Hub.ipa` через eSign и запуск.
2. Импорт вашего `.p12`, `.mobileprovision` и пароля.
3. «Скачать и подписать» для Shadow до конца — с сертификатом, выданным Apple, zsign дополнительно добавляет CMS-подпись (тестовым сертификатом это проверить нельзя).
4. Установка Shadow кнопкой «Установить» (или автоматически после подписи) и его запуск.

## Ограничения

- Успех установки зависит от совместимости `.p12`, `.mobileprovision`, Bundle ID, разрешённых устройств и срока действия профиля; срок действия выбранного сертификата показан на экране.
- Feather хранит сертификат и пароль локально в данных приложения. Не публикуйте резервную копию данных приложения вместе с личными сертификатами. В коде и в этом репозитории сертификатов нет.
- Изменённое приложение распространяется по GPL-3.0: сохраняйте лицензию и публикуйте исходный код.
